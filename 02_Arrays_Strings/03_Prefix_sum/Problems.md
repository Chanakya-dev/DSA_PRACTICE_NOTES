# Prefix Sum – Complete List of DSA Problems

Here is a structured collection of Prefix Sum problems, organized from beginner to advanced level. Solve them category by category so you can build your logic and recognize where Prefix Sum is useful in coding interviews.

## 1. Basic Prefix Sum Problems

Learn how to construct a prefix sum array and answer range-sum queries.

1. Find the Prefix Sum Array
2. Find the Sum of All Elements from Index 0 to Index K
3. Find the Sum of Elements Between Indices L and R
4. Answer Multiple Range Sum Queries
5. Find the Sum of All Prefixes of an Array
6. Find the Sum of All Suffixes of an Array
7. Find the Sum of Elements Except the Current Element
8. Find the Range Sum Using a Prefix Sum Array
9. Find the Average of Elements in a Given Range
10. Find the Sum of Elements at Even and Odd Indices Using Prefix Arrays

## 2. Prefix Sum with HashMap

These problems combine prefix sums with hashing to efficiently track previously seen prefix sums.

1. Subarray Sum Equals K
2. Count the Number of Subarrays with Sum Zero
3. Find the Longest Subarray with Sum K
4. Find the Longest Subarray with Sum Zero
5. Count Subarrays Whose Sum Is Divisible by K
6. Find the Longest Subarray Whose Sum Is Divisible by K
7. Find the Number of Subarrays with Equal Numbers of 0s and 1s
8. Find the Longest Subarray with Equal Numbers of 0s and 1s
9. Count Subarrays with Equal Numbers of Even and Odd Elements
10. Find the Longest Subarray with Equal Numbers of Even and Odd Elements
11. Count Subarrays with Equal Numbers of 0s, 1s and 2s
12. Count Subarrays with XOR Equal to K
13. Find the Longest Subarray with XOR Equal to K
14. Count Subarrays with the Same Remainder Modulo K
15. Find the Number of Subarrays with Sum at Most K — use an appropriate additional technique when needed; a simple prefix-sum HashMap alone is not sufficient.

## 3. Prefix Sum with Two Pointers or Sliding Window

These problems help you understand when Prefix Sum can be combined with window-based techniques. For non-negative arrays, a sliding window can often be simpler than Prefix Sum.

1. Find a Subarray with a Given Sum
2. Find the Smallest Subarray with Sum at Least K (positive elements)
3. Find the Longest Subarray with Sum at Most K (non-negative elements)
4. Count Subarrays with Sum Less Than or Equal to K (non-negative elements)
5. Count Subarrays with Sum Exactly K (non-negative elements)
6. Find the Maximum Sum of a Subarray of Size K
7. Find the Minimum Sum of a Subarray of Size K
8. Find the Maximum Average Subarray of Size K
9. Find the Number of Subarrays with Exactly K Odd Numbers
10. Binary Subarrays With Sum

## 4. Prefix Sum with Difference Arrays

Use this category when multiple range updates need to be applied efficiently before constructing the final array.

1. Apply Multiple Range Increment Operations
2. Apply Multiple Range Decrement Operations
3. Perform Range Addition Queries
4. Find the Final Array After Multiple Range Updates
5. Find the Maximum Element After Range Updates
6. Find the Minimum Element After Range Updates
7. Find the Maximum Overlapping Intervals
8. Find the Number of Overlapping Intervals at Each Index
9. Car Pooling
10. Corporate Flight Bookings

## 5. Prefix Sum with Matrix / 2D Arrays

Learn to calculate sums of rectangular regions in a matrix in constant time after preprocessing.

1. Find the Prefix Sum Matrix
2. Find the Sum of a Rectangular Submatrix
3. Answer Multiple 2D Range Sum Queries
4. Find the Sum of All Submatrices
5. Find the Maximum Sum Submatrix of a Given Size
6. Find the Minimum Sum Submatrix of a Given Size
7. Count Submatrices with Sum Equal to K
8. Find the Maximum Sum Rectangle in a Matrix
9. Find the Number of Submatrices with Sum Zero
10. Find the Largest Square Submatrix with a Given Sum (requires additional techniques)

## 6. Prefix Sum with Binary Arrays

These problems are especially useful for learning transformations and frequency counting.

1. Find the Number of Ones in a Range
2. Find the Longest Subarray with Equal 0s and 1s
3. Count Subarrays with Equal 0s and 1s
4. Find the Maximum Length of a Contiguous Subarray with Equal 0s and 1s
5. Count Binary Subarrays with Sum Equal to K
6. Find the Minimum Number of Flips to Make a Range All Ones (with suitable preprocessing)
7. Count Subarrays with More Ones Than Zeros
8. Find the Longest Subarray with More Ones Than Zeros

## 7. Prefix Sum with Mathematical Transformations

These problems develop the ability to transform an array before applying prefix sums.

1. Find the Pivot Index
2. Find the Equilibrium Index
3. Find All Equilibrium Indices
4. Find the Left Sum and Right Sum for Every Index
5. Find the Number of Ways to Split an Array into Two Parts with Equal Sum
6. Find the Number of Ways to Split an Array into Three Parts with Equal Sum
7. Find the Middle Index Where Left and Right Sums Are Equal
8. Find the Maximum Difference Between Left and Right Subarray Sums
9. Find the Number of Splits Where Left Sum Is Greater Than or Equal to Right Sum
10. Product of Array Except Self — related prefix/suffix technique, but uses products rather than sums.
