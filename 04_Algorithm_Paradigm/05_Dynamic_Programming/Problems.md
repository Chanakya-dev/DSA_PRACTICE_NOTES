My recommendation: Don't attempt all these problems randomly. Start with Fibonacci, Climbing Stairs, Min Cost Climbing Stairs, Frog Jump, and House Robber. For each problem, learn to define the DP state, identify the base cases, write the recurrence relation, implement memoization, and then convert it into tabulation.

This progression will help you recognize DP patterns rather than memorize individual solutions.
