# Recursion — Complete List of Practice Problems

Practice these problems in order, from beginner to advanced. This list focuses specifically on recursion, before moving deeply into backtracking, divide and conquer, and dynamic programming.

## 1. Basic Recursion Problems

1. Print numbers from 1 to N.
2. Print numbers from N to 1.
3. Print even numbers from 1 to N.
4. Print odd numbers from 1 to N.
5. Find the sum of the first N natural numbers.
6. Find the factorial of a number.
7. Calculate \\(a^b\\) using recursion.
8. Find the Nth Fibonacci number.
9. Count the number of recursive calls in a given method.
10. Print a given message N times using recursion.

## 7. Recursion Tracing and Call-Stack Problems
