## Recommended learning order

| Stage | Focus                                 |
| ----- | ------------------------------------- |
| 1     | Basic greedy decisions                |
| 2     | Array-based greedy                    |
| 3     | Interval scheduling                   |
| 4     | Job scheduling                        |
| 5     | Fractional knapsack and coin problems |
| 6     | String-based greedy                   |
| 7     | Greedy with priority queues           |
| 8     | Graph-based greedy                    |
| 9     | Advanced problems and counterexamples |

My recommendation: Start with the first 10 basic problems. For every problem, write down the greedy rule, explain why it works, implement it in Java, and test an example where a different choice would fail. This will help you understand greedy algorithms instead of simply memorizing solutions.
