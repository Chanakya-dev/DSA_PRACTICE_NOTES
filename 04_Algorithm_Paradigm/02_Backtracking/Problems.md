# Backtracking — Complete List of Practice Problems

## 1. Basic Backtracking Problems

1. Generate all binary strings of length N.
2. Generate all strings of length N using characters `A` and `B`.
3. Generate all subsets of an array.
4. Generate all subsequences of a string.
5. Generate all subsets of a string.
6. Generate all combinations of size K from numbers 1 to N.
7. Generate all permutations of an array.
8. Generate all permutations of a string.
9. Generate all combinations that sum to a target.
10. Generate all valid parentheses combinations.

## 2. Array-Based Backtracking Problems

1. Find all subsets whose sum equals a target.
2. Find all combinations of array elements that sum to a target.
3. Find all unique subsets when duplicates exist.
4. Find all unique permutations when duplicates exist.
5. Partition an array into two subsets with equal sums.
6. Partition an array into K subsets with equal sums.
7. Find a subset with a given sum.
8. Find all possible ways to assign `+` and `-` signs to array elements to reach a target.
9. Find all combinations of elements without repeating an index.
10. Find all combinations when an element can be reused.

## 3. String-Based Backtracking Problems

1. Generate all permutations of a string.
2. Generate all subsequences of a string.
3. Generate all possible letter combinations of a phone number.
4. Generate all valid parentheses.
5. Restore all valid IP addresses from a digit string.
6. Partition a string into palindromic substrings.
7. Find all possible sentences formed using a dictionary of words.
8. Generate all expressions by inserting operators to reach a target.
9. Find all possible character combinations from a given set.
10. Solve a word pattern matching problem using backtracking.

## 4. Constraint-Based Backtracking Problems

1. Solve the N-Queens problem.
2. Solve Sudoku.
3. Solve a crossword puzzle.
4. Solve a maze with obstacles.
5. Find a path through a grid while avoiding blocked cells.
6. Solve a Knight's Tour problem.
7. Graph coloring with M colors.
8. Determine whether a Hamiltonian path exists.
9. Determine whether a Hamiltonian cycle exists.
10. Solve a cryptarithmetic puzzle, such as SEND + MORE = MONEY.

## 5. Grid and Matrix Backtracking Problems

1. Find all paths from the top-left to the bottom-right of a grid.
2. Find all paths in a maze moving in four directions.
3. Find all paths in a maze without revisiting cells.
4. Find a word in a character grid.
5. Find all occurrences of a word in a grid.
6. Find all words from a dictionary in a grid.
7. Count paths through a grid with obstacles.
8. Find a Hamiltonian path through a grid.
9. Find all simple paths between two cells.
10. Solve a Sudoku board.

## 6. Combination and Partition Problems

1. Combination Sum.
2. Combination Sum II.
3. Combination Sum III.
4. Subset Sum.
5. Palindrome Partitioning.
6. Partition to K Equal Sum Subsets.
7. Matchsticks to Square.
8. Tug of War — divide elements into two groups with nearly equal sums.
9. Split a string into valid dictionary words.
10. Find all ways to partition a set into nonempty subsets.

## 7. Advanced Backtracking Problems

1. Word Search II.
2. N-Queens II — count all valid arrangements.
3. Sudoku Solver with efficient constraint checking.
4. Rat in a Maze with all possible paths.
5. Knight's Tour.
6. Maximum number of unique substrings in a string.
7. Expression Add Operators.
8. Remove Invalid Parentheses.
9. Fair distribution of cookies among K children.
10. Minimum number of squares needed to tile a rectangle.

## Recommended Learning Order

| Stage | Focus                                     |
| ----- | ----------------------------------------- |
| 1     | Binary strings, subsets and subsequences  |
| 2     | Permutations and combinations             |
| 3     | Combination Sum and Subset Sum            |
| 4     | String partitioning and valid parentheses |
| 5     | Maze paths and grid search                |
| 6     | N-Queens, Sudoku and graph coloring       |
| 7     | Advanced constraint optimization problems |

Core pattern to master: Choose → Explore recursively → Undo.

Start with generating binary strings, then subsets, then permutations. These three problems will help you understand the backtracking template before moving to harder interview questions.
