# Divide and Conquer — Problem List

## Recommended learning order

For your Java DSA practice, solve these in the following order:

| Stage           | Problems to master                           |
| --------------- | -------------------------------------------- |
| 1. Foundations  | Maximum, minimum, sum of an array            |
| 2. Searching    | Binary search, first and last occurrence     |
| 3. Sorting      | Merge sort, quicksort                        |
| 4. Arrays       | Maximum subarray sum, majority element       |
| 5. Counting     | Inversion count, reverse pairs               |
| 6. Mathematical | Fast exponentiation, Fibonacci fast doubling |
| 7. Advanced     | Quickselect, median of two sorted arrays     |
| 8. Expert       | Closest pair of points, Karatsuba, Strassen  |

Important distinction: Divide and Conquer is not the same as recursion. Recursion is a technique for solving problems through smaller calls; Divide and Conquer is a strategy that uses division, subproblem solving, and combination. Binary search, merge sort, and quicksort are excellent examples to study first.
