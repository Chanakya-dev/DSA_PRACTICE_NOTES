# Foundation Problems for Arrays and Strings

7. Calculate the factorial of a number.
8. Print the multiplication table of a number.
9. Count the digits in a number.
10. Find the sum of the digits of a number.
11. Reverse a number.
12. Check whether a number is a palindrome.
13. Check whether a number is prime.
14. Print all prime numbers in a given range.
15. Find the GCD and LCM of two numbers.

## 5. Basic Array and String Logic Problems

These are slightly more challenging and prepare you to recognize patterns before studying specific algorithms.

4. Find the first repeating element.
5. Find the first non-repeating element.

## 6. Indexing and Modification Fundamentals

These problems prepare you for Two Pointers and in-place algorithms. They are foundational exercises, not a replacement for learning those techniques.

1. Swap two array elements using a temporary variable.
2. Reverse an array using a loop.
3. Reverse a string using a character array.
4. Left-rotate an array by one position.
5. Right-rotate an array by one position.
6. Insert an element at a specified index.
7. Delete an element at a specified index.
8. Move all zeros to the end using an additional array.
9. Merge two arrays.
10. Merge two sorted arrays using basic iteration.

## Recommended practice order

## Your foundation checklist

### 0/6

Basic programming and logic (15 problems)

Loops and patterns (8 problems)

Basic arrays (20 problems)

Basic strings (20 problems)

Array and string logic (15 problems)

Indexing and modification (10 problems)

You don't need to master every problem before progressing. Try solving each independently, explain your logic, and analyze its time and space complexity.

After these foundations, follow this sequence:

1. Arrays and Strings fundamentals
2. Two Pointers
3. Sliding Window
4. Prefix Sum
5. Hashing
6. Prefix Sum + HashMap
7. Binary Search and Sorting
8. Stack, Queue, Linked List, Trees, and Graphs

One important rule: initially solve problems using straightforward loops and conditions. Once you understand the brute-force solution, learn how algorithmic techniques optimize it.
