# Sorting — Complete DSA Problem List

Here is a structured collection of Sorting problems for your Java DSA preparation, organized from beginner to advanced. The goal is to learn the sorting algorithms first and then practice problems where sorting helps solve a larger problem.

Start with simple problems involving array ordering and element comparisons.

1. Sort an Array in Ascending Order
2. Sort an Array in Descending Order
3. Sort an Array of Strings Alphabetically
4. Sort an Array of Characters
5. Sort an Array of Negative and Positive Numbers
6. Sort an Array of Even and Odd Numbers
7. Sort an Array of 0s and 1s
8. Sort an Array Containing Only 0s, 1s, and 2s
9. Find the Smallest Element After Sorting
10. Find the Largest Element After Sorting
11. Find the Kth Smallest Element Using Sorting
12. Find the Kth Largest Element Using Sorting
13. Find the Median of an Array Using Sorting
14. Check Whether Two Arrays Are Equal After Sorting
15. Find the Minimum Difference Between Any Two Elements
